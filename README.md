# toolbox

独立维护的个人实用工具合集。各项目位于对应的类别目录，独立安装、运行和测试。

## 工具

| 工具 | 类型 | 说明 |
| --- | --- | --- |
| [shoe-view-downloader](extensions/shoe-view-downloader/) | 浏览器扩展 | 鞋图四视图下载器 |
| [VoiceWave ASR](desktop/voicewave-asr/) | Windows 桌面工具 | WAV 波形裁剪、停顿检测、批量裁剪和本地语音识别 |

## 目录

- `extensions/`：Chrome、Edge 等 Chromium 浏览器扩展。
- `desktop/`：Windows 等桌面应用。
- `userscripts/`：Tampermonkey、Violentmonkey 脚本，在添加首个项目时创建。
- `docs/`：仓库级文档。

各工具保留自身源码、配置、依赖和说明。
